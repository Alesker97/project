# Проверка производительности

Бенчмарк `python -m benchmarks.crawler_benchmark` поднимает локальный HTTP-сервер и сравнивает последовательную загрузку с парсингом и `AdvancedCrawler` на одинаковых наборах из 100, 500 и 1000 страниц. Для каждого запуска он проверяет число страниц, измеряет время через `time.perf_counter()` и пиковую память Python через `tracemalloc`. Результат сохраняется в `output/benchmark.json`.

| Страниц | Последовательно | Асинхронно | Отношение времени | Пик памяти асинхронного обхода |
| ---: | ---: | ---: | ---: | ---: |
| 100 | 1,07 с | 0,31 с | 3,51× | 3,5 МиБ |
| 500 | 3,57 с | 1,42 с | 2,52× | 4,3 МиБ |
| 1000 | 7,23 с | 2,98 с | 2,42× | 5,0 МиБ |

Это измерения одного локального запуска; времена зависят от машины. Синхронный образец последовательно загружает и разбирает страницы, а асинхронный краулер дополнительно хранит результаты и управляет очередью, поэтому значения памяти не являются сравнением одинаковых структур данных. Отсутствие реальной сетевой задержки делает такой тест проверкой накладных расходов и масштабирования локального обхода. Тестовый набор запускает короткую версию бенчмарка на 10 страниц для проверки самого сценария.
