# Алгоритм парсинга HTML

## Назначение

HTML-парсер преобразует загруженную веб-страницу в структурированный набор данных.

Парсер извлекает:

- заголовок страницы;
- основной текст;
- метаданные;
- ссылки;
- изображения;
- заголовки `h1`, `h2`, `h3`;
- таблицы;
- маркированные списки;
- нумерованные списки.

Основной компонент — класс `HTMLParser`, расположенный в модуле:

```text
src/parsers/html_parser.py
```

## Используемые библиотеки

Для разбора HTML используются:

- `beautifulsoup4`;
- `lxml`.

BeautifulSoup предоставляет интерфейс поиска и извлечения HTML-элементов.

`lxml` используется как производительный HTML-парсер, способный восстанавливать многие неправильно закрытые и вложенные теги.

## Асинхронный запуск

Метод `parse_html()` объявлен асинхронным:

```python
async def parse_html(
    self,
    html: str,
    url: str,
) -> dict[str, object]
```

Сам BeautifulSoup работает синхронно. Чтобы разбор HTML не блокировал цикл событий, синхронный метод `_parse_html()` запускается через:

```python
asyncio.to_thread()
```

Это позволяет одновременно загружать новые страницы и обрабатывать уже полученный HTML.

## Структура результата

Парсер возвращает словарь следующего формата:

```python
{
    "url": "https://example.com",
    "title": "Example Domain",
    "text": "Текст страницы",
    "links": [
        "https://example.com/about",
    ],
    "metadata": {
        "title": "Example Domain",
        "description": "Описание страницы",
        "keywords": "example, domain",
    },
    "images": [
        {
            "src": "https://example.com/logo.png",
            "alt": "Логотип",
        }
    ],
    "headings": [
        {
            "level": "h1",
            "text": "Главный заголовок",
        }
    ],
    "tables": [
        [
            ["Имя", "Возраст"],
            ["Алексей", "30"],
        ]
    ],
    "lists": [
        {
            "type": "ul",
            "items": [
                "Первый пункт",
                "Второй пункт",
            ],
        }
    ],
}
```

Структура создаётся до начала извлечения данных. Поэтому даже при ошибках парсер возвращает словарь с исходным URL и пустыми значениями.

## Общий алгоритм парсинга

Метод `_parse_html()` выполняет следующие действия:

1. Создаёт пустую структуру результата.
2. Создаёт объект `BeautifulSoup`.
3. Извлекает метаданные.
4. Записывает заголовок страницы.
5. Извлекает основной текст.
6. Извлекает и нормализует ссылки.
7. Извлекает изображения.
8. Извлекает заголовки `h1`, `h2`, `h3`.
9. Преобразует таблицы в списки строк и ячеек.
10. Извлекает маркированные и нумерованные списки.
11. Возвращает заполненную структуру.

Каждый этап извлечения обрабатывается отдельно. Ошибка одного этапа не удаляет данные, полученные на предыдущих этапах.

## Извлечение текста

Метод `extract_text()` принимает объект BeautifulSoup и необязательный CSS-селектор:

```python
extract_text(soup)
```

возвращает текст всей страницы.

```python
extract_text(soup, "main")
```

возвращает текст первого элемента, соответствующего селектору `main`.

При извлечении исключается содержимое элементов:

- `script`;
- `style`;
- `noscript`;
- `title`.

Лишние пробельные символы нормализуются.

Если элемент по CSS-селектору не найден, возвращается пустая строка.

## Извлечение метаданных

Метод `extract_metadata()` извлекает:

- содержимое элемента `<title>`;
- `<meta name="description">`;
- `<meta name="keywords">`.

Результат всегда содержит три ключа:

```python
{
    "title": "",
    "description": "",
    "keywords": "",
}
```

Если соответствующий элемент отсутствует, его значением остаётся пустая строка.

Если на странице находится несколько одинаковых метатегов, используется первое непустое значение.

## Извлечение ссылок

Метод `extract_links()` находит элементы `<a>` с атрибутом `href`.

Для каждой ссылки выполняются следующие действия:

1. Удаляются лишние пробелы.
2. Пустые значения отбрасываются.
3. Ссылки только на фрагмент страницы отбрасываются.
4. Относительный адрес преобразуется в абсолютный.
5. Из адреса удаляется фрагмент `#section`.
6. Проверяется схема URL.
7. Проверяется наличие домена.
8. Повторяющиеся ссылки удаляются.

Разрешены только схемы:

```text
http
https
```

Поэтому не включаются:

```text
mailto:
tel:
javascript:
```

Внутренние и внешние HTTP-ссылки сохраняются.

## Извлечение изображений

Метод `extract_images()` находит элементы `<img>`.

Для каждого изображения извлекаются:

- `src`;
- `alt`.

Относительный `src` преобразуется в абсолютный URL.

Принимаются только изображения с корректным HTTP- или HTTPS-адресом.

Изображения без `src`, с пустым `src` или с `data:`-адресом отбрасываются.

Если атрибут `alt` отсутствует, возвращается пустая строка.

## Извлечение заголовков

Метод `extract_headings()` извлекает:

- `h1`;
- `h2`;
- `h3`.

Каждый заголовок представляется словарём:

```python
{
    "level": "h1",
    "text": "Главный заголовок",
}
```

Пустые заголовки не добавляются.

Элементы `h4`, `h5` и `h6` на текущем этапе не извлекаются.

## Извлечение таблиц

Метод `extract_tables()` находит все элементы `<table>`.

Каждая таблица преобразуется в список строк, а каждая строка — в список текстовых значений ячеек:

```python
[
    [
        ["Имя", "Возраст"],
        ["Алексей", "30"],
    ]
]
```

Обрабатываются ячейки:

- `<th>`;
- `<td>`.

Пустые таблицы и строки без ячеек не добавляются.

## Извлечение списков

Метод `extract_lists()` обрабатывает:

- `<ul>` — маркированные списки;
- `<ol>` — нумерованные списки.

Результат содержит тип списка и его элементы:

```python
{
    "type": "ol",
    "items": [
        "Первый шаг",
        "Второй шаг",
    ],
}
```

Извлекаются непосредственные дочерние элементы `<li>` каждого списка.

Пустые списки не добавляются.

## Обработка некорректного HTML

`lxml` и BeautifulSoup восстанавливают многие виды некорректной разметки:

- незакрытые теги;
- отсутствующие элементы `html` и `body`;
- неправильную вложенность;
- незакрытые ссылки и абзацы.

Если объект BeautifulSoup создать невозможно, парсер:

1. Записывает предупреждение в журнал.
2. Возвращает пустую структуру результата.
3. Сохраняет исходный URL.

## Частичный результат

Каждый тип данных извлекается в отдельном блоке обработки ошибок.

Если, например, не удалось извлечь ссылки:

- поле `links` остаётся пустым;
- метаданные сохраняются;
- текст сохраняется;
- изображения и остальные элементы продолжают обрабатываться;
- в журнал записывается предупреждение.

Таким образом, одна ошибка не уничтожает весь результат страницы.

## Интеграция с AsyncCrawler

В классе `AsyncCrawler` используется композиция:

```python
self._parser = HTMLParser()
```

Метод `fetch_and_parse()` выполняет два последовательных этапа:

1. Загружает страницу через `fetch_url()`.
2. Передаёт полученный HTML в `HTMLParser.parse_html()`.

Сигнатура метода:

```python
async def fetch_and_parse(
    self,
    url: str,
) -> dict[str, object]
```

Если загрузка завершилась HTTP-ошибкой, таймаутом или сетевой ошибкой, `fetch_url()` возвращает пустую строку.

Парсер принимает пустую строку и возвращает корректную структуру с исходным URL и пустыми данными.

## Параллельная загрузка и парсинг

Несколько вызовов `fetch_and_parse()` могут запускаться через `asyncio.gather()`.

При этом:

- сетевые запросы выполняются конкурентно;
- количество одновременных запросов ограничивается семафором;
- соединения повторно используются через пул;
- разбор HTML выполняется в рабочих потоках;
- результат каждой страницы сохраняется отдельно.

## Логирование

`AsyncCrawler` журналирует:

- начало загрузки URL;
- успешную загрузку;
- сетевые ошибки;
- HTTP-ошибки;
- таймауты;
- начало парсинга;
- завершение парсинга.

`HTMLParser` журналирует предупреждения при невозможности:

- разобрать HTML;
- извлечь метаданные;
- извлечь текст;
- извлечь ссылки;
- извлечь изображения;
- извлечь заголовки;
- извлечь таблицы;
- извлечь списки.

## Тестирование

Парсер тестируется на заранее подготовленном HTML без обращения к интернету.

Проверяются:

- валидный HTML;
- пустой HTML;
- повреждённый HTML;
- текст всей страницы;
- текст по CSS-селектору;
- заголовок страницы;
- description и keywords;
- относительные ссылки;
- абсолютные ссылки;
- удаление фрагментов URL;
- фильтрация неподдерживаемых схем;
- удаление повторяющихся ссылок;
- изображения;
- заголовки;
- таблицы;
- списки;
- частичный результат при ошибке.

Интеграционные тесты используют локальный сервер `aiohttp.web` и проверяют совместную работу `AsyncCrawler` и `HTMLParser`.

## Ограничения текущей реализации

На текущем этапе парсер:

- не выполняет JavaScript;
- не видит данные, которые появляются только после выполнения JavaScript;
- не определяет кодировку самостоятельно вне возможностей `aiohttp`;
- не фильтрует внешние HTTP-ссылки;
- не анализирует вложенные таблицы отдельно;
- не сохраняет результаты в файлы или базу данных;
- не выполняет повторные попытки парсинга;
- не обрабатывает `robots.txt`.
