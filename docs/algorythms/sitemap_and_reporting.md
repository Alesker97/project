# Sitemap, статистика и отчёты

## SitemapParser

`SitemapParser.fetch_sitemap(url)` асинхронно загружает XML и возвращает URL страниц в порядке появления. Для `<urlset>` он извлекает `<url><loc>`. Для `<sitemapindex>` рекурсивно загружает вложенные файлы и объединяет результаты. Пространства имён XML учитываются по локальному имени элемента. Относительные адреса разрешаются относительно файла sitemap.

Множества посещённых sitemap и найденных страниц устраняют циклы и дубликаты. `max_sitemaps` ограничивает число загружаемых файлов; некорректный XML или HTTP-адрес вызывает исключение. Разбор XML выполняется в рабочем потоке, чтобы крупный файл не блокировал цикл событий. Самостоятельный парсер использует собственную HTTP-сессию и закрывает её через `close()`.

`AdvancedCrawler` передаёт парсеру загрузчик на основе `AsyncCrawler`: запросы sitemap проходят через скоростной лимит, повторы и, если включено, проверку `robots.txt`. URL из sitemap объединяются со стартовыми URL перед обходом. Ошибка одного sitemap записывается в `sitemap_errors`; остальные источники продолжают обрабатываться.

## CrawlerStats

`AdvancedCrawler.get_stats()` возвращает `CrawlerStats` с полями `total_pages`, `successful`, `failed`, `average_speed`, `status_codes`, `top_domains`, `run_time`, `active_tasks`, `queued`, `target_pages`, `progress_percent` и `eta_seconds`. В распределении статусов учитывается конечный HTTP-ответ каждой обработанной страницы; ошибки без HTTP-ответа не имеют статус-кода. Топ доменов считается по обработанным URL, включая неудачные.

Время работы включает загрузку sitemap и обход. До завершения процент и оценка времени считаются относительно `max_pages`; при исчерпании доступных URL обход считается завершённым и итоговый прогресс равен 100%. Прогресс в консоли показывает скорость, активные задачи и примерное время до лимита страниц. Вывод ограничен одним обновлением за 0,5 секунды.

`export_to_json(path)` записывает сводку в JSON. `export_to_html_report(path)` создаёт самостоятельную HTML-страницу с таблицами статусов и доменов, а также столбиками их относительных значений. Экспорт вызывается на `AdvancedCrawler` или на объекте `CrawlerStats`.

## Логи

`configure_logging(path, level, max_bytes, backup_count)` настраивает JSON-сообщения в консоли и в файле с ротацией. Запись содержит UTC-время, уровень, имя логгера и текст; поля `url`, `attempt` и `status_code` добавляются, когда они переданы через `extra`. Допустимые уровни: `DEBUG`, `INFO`, `WARNING`, `ERROR`.
