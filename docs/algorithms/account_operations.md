# Алгоритмы работы с банковским счётом

## Создание счёта

При создании счёта выполняются следующие действия:

1. Проверяется имя владельца.
2. Имя должно быть непустой строкой.
3. Начальный баланс преобразуется в `Decimal`.
4. Начальный баланс проверяется на отрицательное значение.
5. Проверяется принадлежность статуса к `AccountStatus`.
6. Проверяется переданный идентификатор счёта.
7. Если идентификатор не передан, создаются восемь символов UUID.
8. Проверяется принадлежность валюты к `Currency`.
9. После успешных проверок создаётся объект счёта.

Переданный идентификатор должен быть строкой длиной не менее четырёх символов.

## Проверка денежного значения

Денежные значения могут иметь тип:

- `Decimal`;
- `int`;
- `float`.

Строковые значения и логические значения `True` и `False` не принимаются.

Проверка выполняется в следующем порядке:

1. Проверяется допустимый тип.
2. Значение преобразуется в `Decimal`.
3. Проверяется, что значение является конечным числом.
4. Для начального баланса допускается значение, равное нулю.
5. Для пополнения и снятия сумма должна быть строго больше нуля.

Значения `NaN`, `Infinity` и `-Infinity` запрещены.

## Проверка статуса

Перед выполнением операции проверяется статус счёта.

| Статус | Результат |
|---|---|
| `ACTIVE` | Операция разрешена |
| `FROZEN` | Возникает `AccountFrozenError` |
| `CLOSED` | Возникает `AccountClosedError` |

## Пополнение счёта

Метод `deposit()` выполняет следующие действия:

1. Проверяет сумму пополнения.
2. Преобразует сумму в `Decimal`.
3. Проверяет статус счёта.
4. Добавляет сумму к текущему балансу.
5. Возвращает новый баланс.

Если сумма некорректна, возникает `InvalidOperationError`.

Если счёт заморожен или закрыт, баланс не изменяется.

## Снятие средств

Метод `withdraw()` выполняет следующие действия:

1. Проверяет сумму снятия.
2. Преобразует сумму в `Decimal`.
3. Проверяет статус счёта.
4. Сравнивает сумму снятия с текущим балансом.
5. Вычитает сумму из баланса.
6. Возвращает новый баланс.

Если сумма превышает текущий баланс, возникает `InsufficientFundsError`.

Отрицательный баланс не допускается.

## Получение информации

Метод `get_account_info()` возвращает словарь со следующими данными:

- тип счёта;
- полный идентификатор;
- владелец;
- статус;
- баланс;
- валюта.

Баланс возвращается в строковом формате с двумя знаками после точки.

## Строковое представление

Метод `__str__()` возвращает строку, содержащую:

- тип счёта;
- владельца;
- последние четыре символа идентификатора;
- статус;
- баланс;
- валюту.

Полный идентификатор в строковом представлении не выводится.

## Обработка исключений

Все пользовательские исключения наследуются от `BankingError`.

Это позволяет обрабатывать как отдельные ситуации:

- `AccountFrozenError`;
- `AccountClosedError`;
- `InvalidOperationError`;
- `InsufficientFundsError`;

так и все ожидаемые банковские ошибки одним обработчиком `BankingError`.
