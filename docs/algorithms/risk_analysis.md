# Анализ рисков

## Назначение

Класс `RiskAnalyzer` определяет уровень риска банковской транзакции до изменения балансов.

Анализатор использует:

- данные текущей транзакции;
- время выполнения;
- историю запросов;
- историю успешно завершённых операций.

История операций поступает из `AuditLog`.

## Результат анализа

Метод `analyze()` возвращает:

- уровень риска;
- список обнаруженных причин.

Поддерживаются уровни:

- `low`;
- `medium`;
- `high`.

## Крупная сумма

Сумма считается крупной, если она больше или равна `large_amount_threshold`.

Порог передаётся при создании анализатора и должен быть положительным конечным числом.

В учебной модели один числовой порог применяется без пересчёта валют.

Обнаруженная причина:

`large_amount`

## Частые операции

Операции считаются частыми, если количество запросов клиента достигает `frequent_operations_limit` внутри интервала `frequent_operations_window`.

По умолчанию анализируется период в пять минут.

Для подсчёта используются записи `transaction_requested`.

Текущий запрос записывается в аудит до запуска анализа, поэтому он также участвует в подсчёте.

Обнаруженная причина:

`frequent_operations`

## Новый получатель

Получатель считается новым, если клиент ранее не выполнял успешный перевод на этот номер счёта.

Для проверки используются записи `transaction_completed`.

Заблокированные и неуспешные операции не делают получателя известным.

Первый перевод клиента любому получателю считается переводом на новый счёт.

Обнаруженная причина:

`new_recipient`

## Ночная операция

Операция считается ночной, если она анализируется в период:

`00:00 <= время < 05:00`

Используется фактическое время анализа, полученное через `time_provider`.

Обнаруженная причина:

`night_operation`

## Расчёт уровня риска

Каждый обнаруженный признак добавляет один балл.

Уровень определяется следующим образом:

- 0 признаков — `low`;
- 1 признак — `medium`;
- 2 и более признаков — `high`.

Операции низкого и среднего риска разрешаются.

Операции высокого риска блокируются банком.

## Проверка банком

Метод `Bank.process_transaction()` выполняет следующие действия:

1. Проверяет транзакцию и процессор.
2. Проверяет регистрацию счёта отправителя.
3. Определяет клиента по счёту отправителя.
4. Проверяет статус клиента.
5. Записывает запрос в аудит.
6. Запускает анализ риска.
7. Записывает результат анализа.
8. Блокирует высокий риск.
9. Передаёт разрешённую операцию в `TransactionProcessor`.
10. Записывает итог обработки.

## Блокировка операции

При высоком риске:

- процессор не запускается;
- баланс отправителя не меняется;
- баланс получателя не меняется;
- транзакция получает статус `failed`;
- записывается причина блокировки;
- количество попыток остаётся равным нулю;
- в аудит добавляется критическое событие.

Таким образом, блокировка выполняется до списания средств.
