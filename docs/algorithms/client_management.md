# Алгоритмы управления клиентами

## Создание клиента

При создании клиента выполняются следующие действия:

1. Проверяется ФИО.
2. Проверяется ID клиента.
3. Проверяется возраст.
4. Проверяется набор контактов.
5. Проверяется статус клиента.
6. Создаётся пустой список номеров счетов.

ФИО и ID должны быть непустыми строками.

Возраст должен быть целым числом не меньше 18. Логические значения
`True` и `False` возрастом не считаются.

Контакты передаются словарём. Ключ и значение каждого контакта должны
быть непустыми строками.

## Статусы клиента

Поддерживаются два статуса:

- `ACTIVE`;
- `BLOCKED`.

Активный клиент может пройти аутентификацию и выполнять доступные
операции.

Заблокированный клиент не может пройти аутентификацию или открыть и
закрыть счёт.

## Список счетов

При открытии счёта его номер добавляется в список счетов клиента.

Повторное добавление одного номера запрещено.

Свойство `account_ids` возвращает копию списка, поэтому изменение
полученного значения не изменяет данные клиента.

Закрытый счёт остаётся в списке клиента, но получает статус `CLOSED`.

## Контакты

Контакты хранятся во внутреннем словаре клиента.

Свойство `contacts` возвращает копию словаря, поэтому внешний код не
может изменить внутренние данные клиента напрямую.
