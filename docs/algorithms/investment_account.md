# Алгоритмы инвестиционного счёта

## Хранение средств

`InvestmentAccount` разделяет средства на две части:

- свободный баланс;
- инвестиционный портфель.

Портфель хранит суммы для трёх типов активов:

- `stocks`;
- `bonds`;
- `etf`.

При создании счёта сумма каждого типа актива равна нулю.

## Размещение средств

Метод `invest()` выполняет следующие действия:

1. Проверяет принадлежность типа актива к `AssetType`.
2. Проверяет корректность суммы.
3. Проверяет статус счёта.
4. Сравнивает сумму со свободным балансом.
5. Уменьшает свободный баланс.
6. Увеличивает сумму выбранного актива.
7. Возвращает обновлённую сумму выбранного актива.

Если тип актива не поддерживается, возникает
`InvalidOperationError`.

Если свободных денег недостаточно, возникает
`InsufficientFundsError`.

## Снятие средств

Метод `withdraw()` работает только со свободным балансом.

Средства из инвестиционного портфеля автоматически не продаются.

Алгоритм выполняет следующие действия:

1. Проверяет корректность суммы.
2. Проверяет статус счёта.
3. Сравнивает сумму со свободным балансом.
4. Уменьшает свободный баланс.
5. Возвращает новый свободный баланс.

Если свободных денег недостаточно, возникает
`InsufficientFundsError`.

## Стоимость портфеля

Стоимость портфеля рассчитывается как сумма всех распределённых
средств:

`стоимость = stocks + bonds + etf`

Свободный баланс в стоимость портфеля не входит.

## Прогнозируемый годовой прирост

Метод `project_yearly_growth()` принимает словарь годовых ставок.

Словарь должен содержать ставки для всех типов активов:

- `stocks`;
- `bonds`;
- `etf`.

Ставки передаются десятичными дробями:

- `0.10` соответствует 10%;
- `0.04` соответствует 4%;
- `0.07` соответствует 7%.

Расчёт выполняется по формуле:

`прирост = stocks × ставка stocks + bonds × ставка bonds + etf × ставка etf`

Метод возвращает прогнозируемый прирост и не изменяет свободный баланс
или портфель.

Отрицательная ставка допускается и означает ожидаемое снижение
стоимости соответствующего актива.

## Информация о счёте

Метод `get_account_info()` расширяет информацию обычного банковского
счёта следующими значениями:

- распределение средств по активам;
- суммарная стоимость портфеля.

Метод `__str__()` выводит свободный баланс, распределение портфеля и
его суммарную стоимость.
