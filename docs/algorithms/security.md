# Алгоритмы безопасности

## Аутентификация

Метод `authenticate_client()` принимает ID клиента и пароль.

При правильном пароле:

1. Проверяется статус клиента.
2. Счётчик неудачных попыток сбрасывается.
3. Возвращается `True`.

При неправильном пароле:

1. Счётчик неудачных попыток увеличивается.
2. Действие записывается как подозрительное.
3. Проверяется достижение трёх попыток.
4. После третьей попытки клиент блокируется.
5. Возвращается `False`.

Заблокированный клиент не может пройти аутентификацию даже с
правильным паролем.

Неудачная попытка неизвестного клиента также записывается как
подозрительная.

## Подозрительные действия

Банк фиксирует:

- неправильные попытки входа;
- попытки изменить состояние счёта ночью.

Каждая запись содержит:

- ID клиента;
- название действия;
- дату и время.

Свойство `suspicious_actions` возвращает копию списка.

## Ограничение по времени

Операции изменения состояния счёта запрещены с 00:00 включительно до
05:00 исключительно.
