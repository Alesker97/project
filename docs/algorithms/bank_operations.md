# Операции банка

## Добавление клиента

Метод `add_client()`:

1. проверяет уникальность идентификатора клиента;
2. проверяет корректность объекта клиента;
3. сохраняет клиента;
4. сохраняет данные для аутентификации.

Возраст клиента проверяется внутри класса `Client`.

Клиент должен быть не младше 18 лет.

## Открытие счёта

Метод `open_account()`:

1. проверяет допустимость времени операции;
2. находит клиента;
3. проверяет уникальность номера счёта;
4. проверяет соответствие владельца счёта клиенту;
5. сохраняет счёт;
6. добавляет номер счёта клиенту.

Открытие счетов запрещено с `00:00` до `05:00`.

## Закрытие счёта

Метод `close_account()`:

1. проверяет допустимость времени;
2. находит счёт;
3. проверяет его текущий статус;
4. переводит счёт в статус `closed`.

Закрытый счёт остаётся в системе, но операции по нему запрещены.

## Заморозка счёта

Метод `freeze_account()`:

1. проверяет допустимость времени;
2. находит счёт;
3. проверяет его текущий статус;
4. переводит счёт в статус `frozen`.

Замороженный счёт нельзя использовать для пополнения, снятия и переводов.

## Разморозка счёта

Метод `unfreeze_account()`:

1. проверяет допустимость времени;
2. находит счёт;
3. убеждается, что счёт заморожен;
4. переводит счёт в статус `active`.

Закрытый счёт разморозить нельзя.

## Аутентификация

Метод `authenticate_client()` сравнивает переданный пароль с сохранённым.

После успешной проверки счётчик ошибок сбрасывается.

После неудачной проверки:

1. счётчик увеличивается;
2. создаётся запись о подозрительном действии;
3. после третьей ошибки клиент блокируется.

## Поиск счетов

Метод `search_accounts()` возвращает счета, соответствующие переданным условиям поиска.

Если фильтры отсутствуют, возвращаются все счета банка.

## Обработка транзакции

Метод `process_transaction()` объединяет банк, анализатор рисков, аудит и обработчик транзакций.

Последовательность работы:

1. проверяется существование клиента;
2. проверяется регистрация счёта отправителя в банке;
3. проверяется принадлежность счёта клиенту;
4. в аудит записывается `transaction_requested`;
5. `RiskAnalyzer` анализирует транзакцию;
6. в аудит записывается `risk_assessment`;
7. выполняется безусловная проверка ночного времени;
8. ночная операция блокируется независимо от уровня риска;
9. транзакция высокого риска блокируется;
10. разрешённая транзакция передаётся в `TransactionProcessor`;
11. результат сохраняется в аудит;
12. успешная операция регистрируется в истории анализатора.

## Блокировка ночной транзакции

Если текущее время находится между `00:00` и `05:00`:

1. транзакция получает статус `failed`;
2. обработчик транзакций не вызывается;
3. количество попыток остаётся равным нулю;
4. балансы не изменяются;
5. причина отказа сохраняется в транзакции;
6. действие добавляется в `suspicious_actions`;
7. в аудит добавляется `transaction_blocked`;
8. метод возвращает `False`.

## Блокировка высокого риска

Если анализатор возвращает `RiskLevel.HIGH`:

1. транзакция получает статус `failed`;
2. обработчик транзакций не вызывается;
3. балансы счетов не изменяются;
4. причина сохраняется в `failure_reason`;
5. в аудит записывается критическое событие;
6. метод возвращает `False`.

## Результат обработки

После выполнения процессором банк записывает:

- `transaction_completed` для успешной операции;
- `transaction_failed` для неуспешной операции.

Метод возвращает:

- `True`, если транзакция выполнена;
- `False`, если транзакция отклонена или завершилась ошибкой.

## Общий баланс

Метод `get_total_balance()` группирует балансы счетов по валютам.

Значения разных валют не складываются между собой без конвертации.

Результат содержит отдельный баланс для каждой поддерживаемой валюты.

## Рейтинг клиентов

Метод `get_clients_ranking()`:

1. получает заданную валюту;
2. суммирует балансы счетов каждого клиента в этой валюте;
3. сортирует клиентов по убыванию суммы;
4. возвращает список клиентов и рассчитанных балансов.

Счета в других валютах в рейтинг не включаются.
