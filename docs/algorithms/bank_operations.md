# Алгоритмы управления банком

## Хранение данных

Класс `Bank` хранит данные в памяти приложения:

- клиентов по их ID;
- счета по их номерам;
- связь счетов с клиентами;
- пароли;
- количество неудачных входов;
- подозрительные действия.

База данных и внешние API не используются.

## Добавление клиента

Метод `add_client()` выполняет следующие действия:

1. Проверяет тип клиента.
2. Проверяет пароль.
3. Проверяет уникальность ID.
4. Сохраняет клиента.
5. Сохраняет пароль.
6. Создаёт счётчик неудачных входов.

Повторный ID клиента запрещён.

## Открытие счёта

Метод `open_account()` выполняет следующие действия:

1. Находит активного клиента.
2. Проверяет тип счёта.
3. Сравнивает владельца счёта с ФИО клиента.
4. Проверяет уникальность номера счёта.
5. Проверяет разрешённое время.
6. Сохраняет счёт.
7. Сохраняет связь счёта с клиентом.
8. Добавляет номер счёта клиенту.
9. Возвращает номер счёта.

## Закрытие счёта

Метод `close_account()` выполняет следующие действия:

1. Находит активного клиента.
2. Находит счёт.
3. Проверяет принадлежность счёта клиенту.
4. Проверяет разрешённое время.
5. Проверяет, что счёт ещё не закрыт.
6. Устанавливает статус `CLOSED`.

Счёт не удаляется, а его номер остаётся у клиента.

## Заморозка счёта

Метод `freeze_account()`:

1. Находит счёт.
2. Определяет владельца.
3. Проверяет разрешённое время.
4. Проверяет активный статус.
5. Устанавливает статус `FROZEN`.

Заморозить закрытый или уже замороженный счёт нельзя.

## Разморозка счёта

Метод `unfreeze_account()`:

1. Находит счёт.
2. Определяет владельца.
3. Проверяет разрешённое время.
4. Проверяет статус `FROZEN`.
5. Устанавливает статус `ACTIVE`.

Разморозить активный или закрытый счёт нельзя.

## Поиск счетов

Метод `search_accounts()` поддерживает фильтры:

- ID клиента;
- статус счёта;
- валюта.

Фильтры можно комбинировать. При отсутствии фильтров возвращаются все
счета банка.

## Общий баланс

Метод `get_total_balance()` суммирует балансы отдельно по каждой
валюте.

Смешивание валют не выполняется, поскольку проект не использует
обменные курсы.

Учитывается свойство `balance`. Инвестиционный портфель в расчёт не
включается.

Отрицательный баланс премиального счёта уменьшает итоговую сумму.

## Рейтинг клиентов

Метод `get_clients_ranking()` принимает валюту и выполняет следующие
действия:

1. Создаёт нулевой баланс для каждого клиента.
2. Суммирует счета клиента в выбранной валюте.
3. Сортирует клиентов по убыванию суммы.
4. При равных суммах сортирует по ID.
5. Возвращает список пар «клиент — баланс».

Клиенты без счетов в выбранной валюте получают нулевой баланс.
