# Алгоритмы накопительного счёта

## Создание счёта

При создании `SavingsAccount` выполняются следующие действия:

1. Минимальный остаток преобразуется в `Decimal`.
2. Месячная ставка преобразуется в `Decimal`.
3. Проверяется, что минимальный остаток неотрицательный.
4. Проверяется, что месячная ставка неотрицательная.
5. Выполняется базовая валидация банковского счёта.
6. Проверяется, что начальный баланс не меньше минимального остатка.
7. Сохраняются параметры накопительного счёта.

Месячная ставка передаётся десятичной дробью:

- `0.01` соответствует 1%;
- `0.015` соответствует 1,5%.

## Снятие средств

Метод `withdraw()` выполняет следующие действия:

1. Проверяет корректность суммы.
2. Проверяет статус счёта.
3. Рассчитывает предполагаемый остаток.
4. Сравнивает остаток с `min_balance`.
5. При допустимом остатке изменяет баланс.
6. Возвращает новый баланс.

Если остаток окажется ниже `min_balance`, возникает
`InsufficientFundsError`. Баланс при этом не изменяется.

## Начисление месячного дохода

Метод `apply_monthly_interest()` выполняет следующие действия:

1. Проверяет статус счёта.
2. Умножает текущий баланс на месячную ставку.
3. Добавляет рассчитанный доход к балансу.
4. Возвращает новый баланс.

Расчёт выполняется по формуле:

`новый баланс = баланс + баланс × месячная ставка`

Для замороженного и закрытого счёта начисление запрещено.

## Информация о счёте

Метод `get_account_info()` расширяет информацию обычного банковского
счёта следующими значениями:

- минимальный остаток;
- месячная ставка.

Метод `__str__()` дополнительно выводит минимальный остаток и месячную
ставку в процентах.
