# Алгоритмы премиального счёта

## Создание счёта

При создании `PremiumAccount` выполняются следующие действия:

1. Лимит снятия преобразуется в `Decimal`.
2. Лимит овердрафта преобразуется в `Decimal`.
3. Фиксированная комиссия преобразуется в `Decimal`.
4. Проверяется, что лимит снятия больше нуля.
5. Проверяется, что овердрафт неотрицательный.
6. Проверяется, что комиссия неотрицательная.
7. Выполняется базовая валидация банковского счёта.
8. Сохраняются параметры премиального счёта.

## Снятие средств

Метод `withdraw()` выполняет следующие действия:

1. Проверяет корректность суммы.
2. Проверяет статус счёта.
3. Сравнивает сумму с лимитом одного снятия.
4. Прибавляет к сумме фиксированную комиссию.
5. Рассчитывает доступные средства с учётом овердрафта.
6. Сравнивает полное списание с доступными средствами.
7. Уменьшает баланс на сумму снятия и комиссию.
8. Возвращает новый баланс.

Полное списание рассчитывается по формуле:

`полное списание = сумма снятия + фиксированная комиссия`

Доступные средства рассчитываются по формуле:

`доступные средства = текущий баланс + лимит овердрафта`

Лимит одного снятия применяется к запрошенной сумме без комиссии.

Если сумма превышает лимит снятия, возникает
`InvalidOperationError`.

Если полное списание превышает доступные средства, возникает
`InsufficientFundsError`.

При отклонённой операции баланс не изменяется и комиссия не
списывается.

## Овердрафт

Баланс премиального счёта может быть отрицательным.

Минимально допустимый баланс определяется формулой:

`минимальный баланс = -лимит овердрафта`

Пополнение наследуется от `BankAccount` и уменьшает использованный
овердрафт.

## Информация о счёте

Метод `get_account_info()` расширяет информацию обычного банковского
счёта следующими значениями:

- лимит снятия;
- лимит овердрафта;
- фиксированная комиссия.

Метод `__str__()` выводит эти значения вместе с основной информацией
о счёте.
