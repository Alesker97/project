# Базовая модель банковских счетов

Учебный проект по основам объектно-ориентированного программирования на Python.

Проект реализует абстрактную модель банковского счёта и конкретный класс `BankAccount` с проверкой входящих данных, статусами, валютами и собственными исключениями.

## Возможности

- абстрактный класс `AbstractAccount`;
- наследование `BankAccount` от абстрактного класса;
- автоматическая генерация короткого UUID;
- защищённый баланс;
- использование `Decimal` для денежных значений;
- поддержка нескольких валют;
- проверка статуса перед операциями;
- пополнение и снятие средств;
- защита от отрицательных и некорректных сумм;
- собственные классы исключений;
- строковое представление счёта;
- автоматические тесты на `pytest`.

## Статусы счетов

| Статус | Описание |
|---|---|
| `ACTIVE` | Счёт активен, операции разрешены |
| `FROZEN` | Счёт заморожен, операции запрещены |
| `CLOSED` | Счёт закрыт, операции запрещены |

## Установка

Перейти в корневую папку проекта и создать виртуальное окружение:

```powershell
python -m venv .venv
```

Активировать окружение в PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

## Запуск

Из корневой папки проекта выполнить:

```powershell
python -m src.main
```

Программа:

1. создаст активный и замороженный счета;
2. выполнит пополнение активного счёта;
3. выполнит снятие с активного счёта;
4. попытается выполнить операции по замороженному счёту;
5. обработает ожидаемые исключения;
6. выведет итоговое состояние счетов.

## Запуск тестов

```powershell
python -m pytest -v
```

Тесты проверяют:

- абстрактный контракт `AbstractAccount`;
- создание банковского счёта;
- генерацию идентификатора;
- пополнение и снятие;
- валидацию денежных значений;
- недостаточный баланс;
- активный, замороженный и закрытый статусы;
- допустимые валюты;
- получение информации о счёте;
- строковое представление.
