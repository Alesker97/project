# Модель банковских счетов

Учебный проект для практики объектно-ориентированного программирования
на Python.

Проект реализует абстрактную модель банковского счёта и несколько
дочерних типов счетов с различными правилами выполнения операций.

## Реализованные классы

### AbstractAccount

Абстрактная основа всех счетов:

- идентификатор счёта;
- владелец;
- защищённый баланс;
- статус;
- общий интерфейс операций.

### BankAccount

Базовый банковский счёт:

- пополнение;
- снятие;
- проверка суммы;
- проверка статуса;
- валюта;
- автоматическая генерация короткого UUID.

### SavingsAccount

Накопительный счёт:

- минимальный остаток;
- месячная ставка;
- начисление месячного дохода;
- запрет снятия ниже минимального остатка.

### PremiumAccount

Премиальный счёт:

- увеличенный лимит одного снятия;
- возможность овердрафта;
- фиксированная комиссия;
- снятие средств вместе с комиссией.

### InvestmentAccount

Инвестиционный счёт:

- свободный баланс;
- инвестиционный портфель;
- активы `stocks`, `bonds` и `etf`;
- распределение средств по активам;
- расчёт прогнозируемого годового прироста;
- снятие только свободных средств.

## Иерархия классов

```text
AbstractAccount
└── BankAccount
    ├── SavingsAccount
    ├── PremiumAccount
    └── InvestmentAccount
```

## Полиморфизм

Каждый специализированный тип счёта переопределяет:

- `withdraw()`;
- `get_account_info()`;
- `__str__()`.

Правила снятия зависят от фактического типа объекта:

| Класс | Правило снятия |
|---|---|
| `BankAccount` | Баланс не может стать отрицательным |
| `SavingsAccount` | Нельзя нарушить минимальный остаток |
| `PremiumAccount` | Разрешён овердрафт, учитываются лимит и комиссия |
| `InvestmentAccount` | Снимаются только свободные деньги |

## Статусы

| Статус | Описание |
|---|---|
| `ACTIVE` | Операции разрешены |
| `FROZEN` | Операции запрещены |
| `CLOSED` | Операции запрещены |

## Валюты

Поддерживаются:

- RUB;
- USD;
- EUR;
- KZT;
- CNY.

## Инвестиционные активы

Поддерживаются виртуальные типы активов:

- `stocks`;
- `bonds`;
- `etf`.

Проект является учебной моделью. Он не использует реальные ценные
бумаги, биржевые данные, внешние API или базу данных.

## Исключения

| Исключение | Назначение |
|---|---|
| `AccountFrozenError` | Счёт заморожен |
| `AccountClosedError` | Счёт закрыт |
| `InvalidOperationError` | Переданы некорректные данные |
| `InsufficientFundsError` | Недостаточно средств |
| `BankingError` | Общий родитель банковских ошибок |

## Требования

- Python 3.13.14
- pytest 9.1.1.

## Установка

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Активировать его в PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

## Запуск демонстрации

```powershell
python -m src.main
```

Демонстрация создаёт несколько счетов каждого специализированного
типа и выполняет различные операции:

- начисление месячного дохода;
- снятие с накопительного счёта;
- попытку снятия с замороженного счёта;
- снятие с комиссией;
- использование овердрафта;
- распределение денег между активами;
- расчёт прогнозируемого годового прироста;
- полиморфный вывод информации о счетах.

## Запуск тестов

```powershell
python -m pytest -v
```

Тесты проверяют:

- абстрактный контракт;
- валидацию входящих данных;
- генерацию идентификаторов;
- статусы;
- валюты;
- обычное пополнение и снятие;
- минимальный остаток;
- начисление месячного дохода;
- премиальные лимиты;
- комиссию и овердрафт;
- инвестиционный портфель;
- допустимые типы активов;
- прогнозируемый годовой прирост;
- строковое представление счетов.
