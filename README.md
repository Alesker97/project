# Банковская система

Учебный проект на Python для практики объектно-ориентированного программирования.

Проект представляет упрощённую банковскую систему, которая позволяет создавать клиентов, открывать и управлять банковскими счетами, выполнять операции и контролировать безопасность.

## Возможности проекта

- создание банковских клиентов;
- проверка возраста клиента;
- открытие разных типов счетов;
- пополнение и снятие денежных средств;
- начисление процентов на накопительный счёт;
- использование овердрафта на премиальном счёте;
- формирование инвестиционного портфеля;
- расчёт прогнозируемого роста инвестиций;
- заморозка, разморозка и закрытие счетов;
- аутентификация клиентов;
- блокировка клиента после трёх неверных попыток входа;
- фиксация подозрительных действий;
- запрет операций со счетами с 00:00 до 05:00;
- поиск счетов;
- расчёт общих балансов банка;
- формирование рейтинга клиентов;
- автоматическая генерация номера счёта;
- поддержка нескольких валют.

## Основные сущности

### AbstractAccount

Абстрактный базовый класс банковского счёта.

Содержит:

- уникальный номер счёта;
- имя владельца;
- защищённый баланс;
- валюту;
- статус счёта.

Определяет обязательные методы:

- `deposit()`;
- `withdraw()`;
- `get_account_info()`;
- `__str__()`.

### BankAccount

Базовая реализация банковского счёта.

Поддерживает:

- пополнение счёта;
- снятие денежных средств;
- проверку корректности суммы;
- проверку текущего статуса;
- защиту от отрицательного баланса;
- автоматическую генерацию короткого UUID.

### SavingsAccount

Накопительный счёт.

Дополнительные возможности:

- минимальный допустимый остаток;
- месячная процентная ставка;
- начисление процентов методом `apply_monthly_interest()`.

После снятия средств баланс не может стать меньше установленного минимального остатка.

### PremiumAccount

Премиальный счёт.

Дополнительные возможности:

- увеличенный лимит снятия;
- разрешённый овердрафт;
- фиксированная комиссия за снятие.

При снятии со счёта списывается запрошенная сумма и фиксированная комиссия.

### InvestmentAccount

Инвестиционный счёт.

Поддерживает виртуальный инвестиционный портфель со следующими типами активов:

- `stocks`;
- `bonds`;
- `etf`.

Метод `project_yearly_growth()` рассчитывает ожидаемый годовой прирост портфеля на основании переданных процентных ставок.

Проект использует учебную модель инвестиций. Реальные ценные бумаги, котировки, внешние API и инвестиционные правила не применяются.

### Client

Клиент банка.

Содержит:

- ФИО;
- уникальный идентификатор;
- возраст;
- контактные данные;
- статус;
- список номеров счетов.

Регистрация разрешена только клиентам в возрасте от 18 лет.

### Bank

Управляющий класс банковской системы.

Поддерживает методы:

- `add_client()` — добавление клиента;
- `open_account()` — открытие счёта;
- `close_account()` — закрытие счёта;
- `freeze_account()` — заморозка счёта;
- `unfreeze_account()` — разморозка счёта;
- `authenticate_client()` — аутентификация клиента;
- `search_accounts()` — поиск счетов;
- `get_total_balance()` — расчёт общих балансов;
- `get_clients_ranking()` — формирование рейтинга клиентов.

Данные хранятся в памяти приложения. База данных в текущей версии проекта не используется.

## Статусы

### Статусы счетов

- `active` — счёт активен;
- `frozen` — счёт заморожен;
- `closed` — счёт закрыт.

Операции пополнения и снятия доступны только для активных счетов.

### Статусы клиентов

- `active` — клиент активен;
- `blocked` — клиент заблокирован.

После трёх последовательных неверных попыток входа клиент получает статус `blocked`.

## Валюты

Поддерживаются следующие валюты:

- `RUB`;
- `USD`;
- `EUR`;
- `KZT`;
- `CNY`.

Баланс каждой валюты рассчитывается отдельно. Конвертация валют в проекте не выполняется.

## Безопасность

Банк фиксирует следующие подозрительные действия:

- неудачные попытки аутентификации;
- попытки выполнить операции со счетами в запрещённое время.

Открытие, закрытие, заморозка и разморозка счетов запрещены с 00:00 до 05:00.

Время события сохраняется вместе с идентификатором клиента и названием действия.

Пароли используются только в рамках учебной модели и хранятся в памяти приложения.

## Аналитика

### Общий баланс

Метод `get_total_balance()` возвращает свободные остатки на счетах, сгруппированные по валютам.

Стоимость инвестиционного портфеля не включается в свободный баланс инвестиционного счёта.

### Рейтинг клиентов

Метод `get_clients_ranking()` формирует рейтинг клиентов по общей сумме средств в выбранной валюте.

Разделение по валютам позволяет не складывать суммы без предварительной конвертации.

## Исключения

В проекте используются собственные типы исключений:

- `AccountFrozenError` — операция со счётом запрещена из-за заморозки;
- `AccountClosedError` — операция со счётом запрещена из-за закрытия;
- `InvalidOperationError` — переданы некорректные данные или операция запрещена;
- `InsufficientFundsError` — на счёте недостаточно средств.

## Установка

Клонировать репозиторий:

```bash
git clone <URL-репозитория>
```

Перейти в папку проекта:

```bash
cd <название-папки>
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать виртуальное окружение в PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

## Запуск демонстрации

Из корневой папки проекта выполнить:

```bash
python -m src.main
```

Демонстрация включает:

- создание нескольких клиентов;
- открытие накопительного, премиального и инвестиционного счетов;
- начисление процентов;
- снятие средств с комиссией;
- формирование инвестиционного портфеля;
- расчёт ожидаемого прироста портфеля;
- успешную и неуспешную аутентификацию;
- блокировку клиента после трёх ошибок;
- заморозку и разморозку счёта;
- вывод общих балансов;
- построение рейтинга клиентов;
- фиксацию подозрительных действий;
- попытку выполнить операцию в запрещённое время.

## Запуск тестов

Запустить все тесты:

```bash
python -m pytest -v
```

Конфигурация Pytest находится в файле `pytest.ini`.
