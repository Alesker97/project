# Асинхронный веб-краулер

Учебный проект по параллельности и асинхронности в Python.

Цель проекта — создать модульный асинхронный веб-краулер, способный конкурентно загружать веб-страницы, обрабатывать сетевые ошибки, ограничивать количество одновременных запросов и корректно освобождать сетевые ресурсы.

## Реализованный функционал

Текущая версия проекта поддерживает:

- асинхронную загрузку одной веб-страницы;
- параллельную загрузку списка URL;
- ограничение количества конкурентных запросов;
- повторное использование HTTP-соединений;
- таймаут подключения;
- таймаут чтения ответа;
- обработку HTTP-ошибок;
- обработку сетевых ошибок;
- обработку таймаутов;
- журналирование загрузок и ошибок;
- корректное закрытие HTTP-сессии;
- сравнение последовательной и параллельной загрузки.

## Основные компоненты

### AsyncCrawler

Класс `AsyncCrawler` отвечает за асинхронную загрузку страниц.

Основные методы:

- `fetch_url(url)` — загружает одну веб-страницу;
- `fetch_urls(urls)` — конкурентно загружает список веб-страниц;
- `close()` — закрывает HTTP-сессию и сетевые соединения.

HTTP-сессия создаётся при первом запросе и повторно используется для последующих запросов.

Количество одновременно выполняющихся запросов ограничивается с помощью `asyncio.Semaphore`.

Пул HTTP-соединений управляется через `aiohttp.TCPConnector`.

## Обработка ошибок

Краулер обрабатывает:

- `aiohttp.ClientResponseError` — HTTP-ошибки, например 404 или 500;
- `asyncio.TimeoutError` — превышение времени ожидания;
- `aiohttp.ClientError` — остальные ошибки HTTP-клиента и сети.

Если запрос завершился ошибкой, метод `fetch_url()` возвращает пустую строку. Благодаря этому ошибка одного запроса не останавливает загрузку остальных URL.

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/username/project.git
cd project
```

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Активировать его в PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

Проверить зависимости:

```powershell
python -m pip check
```

## Запуск тестов

Запустить все тесты:

```powershell
python -m pytest -v
```

Тесты используют локальный HTTP-сервер и не зависят от доступности внешних сайтов.

Проверяются:

- параметры инициализации;
- создание HTTP-сессии;
- повторное использование сессии;
- закрытие сессии;
- успешная загрузка страницы;
- обработка HTTP-ошибки;
- обработка таймаута;
- обработка сетевой ошибки;
- загрузка списка URL;
- сохранение ошибочного результата;
- работа с пустым списком;
- преимущество конкурентной загрузки.

## Запуск демонстрации

```powershell
python -m src.main
```

Демонстрационная программа:

1. Загружает шесть URL последовательно.
2. Загружает те же URL параллельно.
3. Выводит статус каждого запроса.
4. Показывает HTTP-ошибки.
5. Измеряет время обоих вариантов.
6. Рассчитывает коэффициент ускорения.

Результат зависит от скорости сети и состояния используемых внешних сайтов.

Пример итогового сравнения:

```text
Время последовательной загрузки: 7.68 сек.
Время параллельной загрузки: 2.89 сек.
Параллельная загрузка быстрее в 2.66 раза.
```
