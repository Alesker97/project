# Асинхронный веб-краулер

Учебный проект асинхронного веб-краулера на Python.

Проект создаётся поэтапно и демонстрирует применение:

- асинхронного программирования;
- конкурентного выполнения сетевых запросов;
- управления HTTP-соединениями;
- парсинга HTML;
- очередей с приоритетами;
- ограничения конкурентности;
- ограничения глубины обхода;
- фильтрации URL;
- обработки сетевых ошибок;
- структурированного логирования;
- тестирования асинхронного кода.

На текущем этапе краулер умеет загружать страницы, извлекать из них структурированные данные и автоматически обходить найденные ссылки.

## Возможности

Реализованы:

- асинхронная загрузка одной страницы;
- параллельная загрузка нескольких страниц;
- повторное использование `aiohttp.ClientSession`;
- connection pooling;
- таймауты подключения и чтения;
- обработка HTTP-ошибок;
- обработка сетевых ошибок;
- обработка таймаутов;
- базовое логирование;
- ограничение общего количества одновременных запросов;
- ограничение запросов к одному домену;
- парсинг HTML;
- извлечение основного текста;
- извлечение метаданных;
- преобразование относительных ссылок в абсолютные;
- извлечение изображений;
- извлечение заголовков `h1`, `h2`, `h3`;
- извлечение таблиц;
- извлечение списков;
- очередь URL с приоритетами;
- защита от повторного добавления URL;
- автоматическое добавление найденных ссылок;

## Асинхронный HTTP-клиент

Класс `AsyncCrawler` находится в файле:

```text
src/crawler/async_crawler.py
```

Пример создания клиента:

```python
crawler = AsyncCrawler(
    max_concurrent=10,
    max_concurrent_per_domain=2,
    max_depth=2,
)
```

Основные методы:

- `fetch_url()` — загрузка одной страницы;
- `fetch_urls()` — параллельная загрузка списка URL;
- `fetch_and_parse()` — загрузка и парсинг одной страницы;
- `crawl()` — автоматический обход страниц;
- `get_crawl_stats()` — получение статистики обхода;
- `close()` — закрытие HTTP-сессии.

## HTTP-сессия и connection pooling

`AsyncCrawler` использует одну экземплярную `aiohttp.ClientSession`.

Сессия создаётся при первом HTTP-запросе и повторно используется при последующих запросах.

Это обеспечивает:

- повторное использование соединений;
- connection pooling;
- сокращение накладных расходов;
- централизованное управление таймаутами;
- корректное освобождение ресурсов.

После завершения работы с клиентом вызывается:

```python
await crawler.close()
```

## Управление конкурентностью

Класс `SemaphoreManager` находится в файле:

```text
src/concurrency/semaphore_manager.py
```

Он управляет двумя ограничениями:

- глобальным количеством одновременных запросов;
- количеством одновременных запросов к одному домену.

Например:

```python
crawler = AsyncCrawler(
    max_concurrent=10,
    max_concurrent_per_domain=2,
)
```

При такой конфигурации одновременно выполняется не более десяти запросов, при этом к одному домену отправляется не более двух запросов.

Менеджер также отслеживает текущее и максимальное количество активных задач.

## Парсинг HTML

Класс `HTMLParser` находится в файле:

```text
src/parsers/html_parser.py
```

Парсер извлекает:

- заголовок страницы;
- основной текст;
- метаданные;
- абсолютные ссылки;
- изображения и их атрибуты;
- заголовки `h1`, `h2`, `h3`;
- таблицы;
- маркированные списки;
- нумерованные списки.

Пример результата:

```python
{
    "url": "https://example.com",
    "title": "Example Domain",
    "text": "Example Domain ...",
    "links": [
        "https://iana.org/help/example-domains"
    ],
    "metadata": {
        "title": "Example Domain",
        "description": "",
        "keywords": ""
    },
    "images": [],
    "headings": [],
    "tables": [],
    "lists": []
}
```

Относительные ссылки преобразуются в абсолютные с помощью базового URL страницы.

Поддерживаются ссылки с протоколами `http` и `https`.

Фрагменты URL удаляются, а повторяющиеся ссылки исключаются.

## Очередь URL

Класс `CrawlerQueue` находится в файле:

```text
src/queues/crawler_queue.py
```

Очередь построена на основе `asyncio.PriorityQueue`.

Каждый элемент очереди содержит:

- приоритет;
- порядковый номер;
- URL.

Чем больше числовое значение приоритета, тем раньше URL будет получен из очереди.

Для URL с одинаковым приоритетом сохраняется порядок добавления.

Очередь отслеживает следующие состояния:

- ожидающие обработки URL;
- активные URL;
- успешно обработанные URL;
- неудачные URL.

Повторное добавление уже известного URL блокируется.

## Управление обходом

Основной обход запускается методом:

```python
results = await crawler.crawl(
    start_urls=["https://example.com"],
    max_pages=50,
    same_domain_only=True,
)
```

Алгоритм обхода:

1. Очищает состояние предыдущего запуска.
2. Проверяет стартовые URL.
3. Добавляет стартовые URL в очередь с глубиной `0`.
4. Получает из очереди очередную группу URL.
5. Загружает и парсит страницы конкурентно.
6. Помечает страницы как обработанные или неудачные.
7. Извлекает найденные ссылки.
8. Проверяет глубину каждой ссылки.
9. Применяет настроенные фильтры.
10. Исключает уже известные URL.
11. Добавляет подходящие ссылки в очередь.
12. Выводит текущую статистику.
13. Останавливается после достижения `max_pages` или опустошения очереди.

Если достигнут лимит `max_pages`, в очереди могут оставаться URL. Это нормальное поведение: они были найдены, но не были обработаны из-за установленного ограничения.

## Глубина обхода

Глубина стартового URL равна `0`.

Ссылки, найденные на стартовой странице, имеют глубину `1`.

Ссылки, найденные на страницах первого уровня, имеют глубину `2`.

Параметр `max_depth` определяет максимальную разрешённую глубину.

Пример:

```python
crawler = AsyncCrawler(max_depth=2)
```

В этом случае будут обработаны страницы с глубиной:

- `0`;
- `1`;
- `2`.

Ссылки с глубиной `3` и больше не добавляются в очередь.

## Фильтрация URL

Метод `crawl()` поддерживает несколько видов фильтрации.

### Только стартовые домены

```python
same_domain_only=True
```

При включённом параметре обрабатываются только URL, домены которых совпадают с доменами стартовых страниц.

### Исключаемые паттерны

```python
exclude_patterns=[
    "/login",
    "/logout",
    "/admin",
]
```

URL пропускается, если содержит хотя бы один исключаемый паттерн.

### Включаемые паттерны

```python
include_patterns=[
    "/docs/",
    "/articles/",
]
```

URL добавляется в очередь только в том случае, если содержит хотя бы один включаемый паттерн.

Проверка паттернов выполняется как поиск подстроки в URL.

## Состояние обхода

`AsyncCrawler` хранит:

- `visited_urls` — множество URL, взятых в обработку;
- `processed_urls` — успешно обработанные URL и полученные данные;
- `failed_urls` — URL, завершившиеся ошибкой, и причины ошибок.

Состояние очищается перед каждым новым вызовом `crawl()`.

Это позволяет повторно использовать один экземпляр краулера для нескольких независимых обходов.

## Статистика

Во время обхода отображаются:

- количество обработанных страниц;
- количество URL в очереди;
- количество ошибок;
- скорость обработки в страницах в секунду.

Статистика также доступна через:

```python
stats = crawler.get_crawl_stats()
```

Результат содержит:

- общее количество попыток обработки;
- количество успешных страниц;
- количество ожидающих URL;
- количество активных задач;
- количество ошибок;
- скорость обработки.

## Обработка ошибок

Краулер обрабатывает:

- HTTP-ошибки;
- сетевые ошибки;
- таймауты;
- некорректные URL;
- ошибки парсинга HTML.

Ошибка одной страницы не останавливает весь обход.

Неудачный URL помещается в `failed_urls`, а остальные страницы продолжают обрабатываться.

## Логирование

Программа логирует:

- начало загрузки URL;
- успешное завершение загрузки;
- HTTP-ошибки;
- сетевые ошибки;
- таймауты;
- начало парсинга;
- успешное завершение парсинга;
- предупреждения при обработке HTML.

Пример:

```text
Начало загрузки URL: https://example.com
Успешная загрузка URL: https://example.com
```
