# Асинхронный веб-краулер

Учебный проект по параллельности и асинхронности в Python.

Цель проекта — создать модульный асинхронный веб-краулер, способный конкурентно загружать веб-страницы, извлекать структурированные данные, обрабатывать ошибки и корректно управлять сетевыми ресурсами.

## Реализованный функционал

Текущая версия проекта поддерживает:

- асинхронную загрузку одной веб-страницы;
- параллельную загрузку списка URL;
- ограничение количества конкурентных запросов;
- повторное использование HTTP-соединений;
- таймаут подключения;
- таймаут чтения ответа;
- обработку HTTP-ошибок;
- обработку сетевых ошибок;
- обработку таймаутов;
- структурированное логирование;
- корректное закрытие HTTP-сессии;
- сравнение последовательной и параллельной загрузки;
- парсинг HTML;
- извлечение текста страницы;
- извлечение текста по CSS-селектору;
- извлечение метаданных;
- извлечение и нормализацию ссылок;
- преобразование относительных URL в абсолютные;
- извлечение изображений;
- извлечение заголовков `h1`, `h2`, `h3`;
- извлечение таблиц;
- извлечение маркированных и нумерованных списков;
- обработку повреждённого HTML;
- возврат частичного результата при ошибках парсинга.

## AsyncCrawler

Класс `AsyncCrawler` отвечает за загрузку веб-страниц и интеграцию с HTML-парсером.

Основные методы:

- `fetch_url(url)` — загружает одну страницу;
- `fetch_urls(urls)` — конкурентно загружает список страниц;
- `fetch_and_parse(url)` — загружает и разбирает страницу;
- `close()` — закрывает HTTP-сессию.

HTTP-сессия создаётся при первом запросе и повторно используется при последующих запросах.

Количество одновременно выполняющихся запросов ограничивается с помощью `asyncio.Semaphore`.

Пул HTTP-соединений управляется через `aiohttp.TCPConnector`.

## HTMLParser

Класс `HTMLParser` отвечает за обработку загруженного HTML.

Основные методы:

- `parse_html(html, url)` — выполняет полный разбор страницы;
- `extract_links(soup, base_url)` — извлекает ссылки;
- `extract_text(soup, selector)` — извлекает текст;
- `extract_metadata(soup)` — извлекает метаданные;
- `extract_images(soup, base_url)` — извлекает изображения;
- `extract_headings(soup)` — извлекает заголовки;
- `extract_tables(soup)` — извлекает таблицы;
- `extract_lists(soup)` — извлекает списки.

BeautifulSoup работает синхронно, поэтому полный разбор страницы запускается через `asyncio.to_thread()`. Это предотвращает блокировку цикла событий во время обработки HTML.

## Формат результата парсинга

Метод `fetch_and_parse()` возвращает словарь:

```python
{
    "url": "https://example.com",
    "title": "Example Domain",
    "text": "Текст страницы",
    "links": [
        "https://example.com/about",
    ],
    "metadata": {
        "title": "Example Domain",
        "description": "Описание страницы",
        "keywords": "example, domain",
    },
    "images": [
        {
            "src": "https://example.com/logo.png",
            "alt": "Логотип",
        }
    ],
    "headings": [
        {
            "level": "h1",
            "text": "Главный заголовок",
        }
    ],
    "tables": [
        [
            ["Имя", "Возраст"],
            ["Алексей", "30"],
        ]
    ],
    "lists": [
        {
            "type": "ul",
            "items": [
                "Первый пункт",
                "Второй пункт",
            ],
        }
    ],
}
```

Если отдельные данные отсутствуют или не могут быть извлечены, соответствующие поля остаются пустыми.

## Обработка ссылок

Парсер:

- преобразует относительные URL в абсолютные;
- принимает только ссылки с протоколами HTTP и HTTPS;
- проверяет наличие домена;
- удаляет фрагменты вида `#section`;
- удаляет повторяющиеся ссылки;
- сохраняет порядок ссылок;
- пропускает пустые ссылки;
- пропускает `mailto:`;
- пропускает `tel:`;
- пропускает `javascript:`.

Внутренние и внешние HTTP-ссылки сохраняются.

## Обработка ошибок загрузки

Краулер обрабатывает:

- `aiohttp.ClientResponseError` — HTTP-ошибки;
- `asyncio.TimeoutError` — таймауты;
- `aiohttp.ClientError` — сетевые ошибки и ошибки HTTP-клиента.

При обработанной ошибке метод `fetch_url()` возвращает пустую строку. Благодаря этому ошибка одного запроса не останавливает остальные задачи.

## Обработка ошибок парсинга

Структура результата создаётся до начала разбора HTML.

Каждый тип данных извлекается независимо. Если один этап завершается ошибкой:

- предупреждение записывается в журнал;
- соответствующее поле остаётся пустым;
- уже извлечённые данные сохраняются;
- остальные этапы продолжают выполняться;
- программа возвращает частичный результат.

BeautifulSoup и `lxml` также восстанавливают многие незакрытые и неправильно вложенные HTML-теги.

## Запуск демонстрации

```powershell
python -m src.main
```

Демонстрационная программа выполняет две части.

### Сравнение способов загрузки

Программа:

1. Загружает шесть URL последовательно.
2. Загружает те же URL параллельно.
3. Выводит статус каждого запроса.
4. Показывает обработку HTTP 404.
5. Измеряет время выполнения.
6. Рассчитывает коэффициент ускорения.

Пример:

```text
Время последовательной загрузки: 6.83 сек.
Время параллельной загрузки: 3.42 сек.
Параллельная загрузка быстрее в 2.00 раза.
```

### Парсинг страниц

Программа загружает и обрабатывает несколько страниц конкурентно.

Для каждой страницы выводятся:

- исходный URL;
- статус;
- заголовок страницы;
- длина текста;
- количество ссылок;
- количество изображений;
- количество заголовков;
- количество таблиц;
- количество списков;
- заголовки `h1`, `h2`, `h3`;
- первые найденные ссылки.

Результаты и время выполнения зависят от скорости сети и текущего содержимого внешних сайтов.

Если сайт недоступен, программа не падает и выводит статус:

```text
данные не получены
```

## Ограничения текущей реализации

На текущем этапе краулер:

- не выполняет JavaScript;
- не видит динамические данные браузерных приложений;
- не выполняет автоматические повторные попытки;
- не ограничивает частоту запросов по времени;
- не обрабатывает `robots.txt`;
- не сохраняет результаты в файлы или базу данных;
- не ведёт общую статистику работы;
- загружает HTTP-ответ целиком в память.

Эти возможности будут добавляться на следующих этапах проекта.
